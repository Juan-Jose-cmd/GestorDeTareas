# ✅ Task Manager

Aplicación sencilla para gestionar tareas.  
Pensada como proyecto rápido y limpio que muestra organización y manejo básico de estado.

## 🚀 Tecnologías Utilizadas
- HTML  
- CSS  
- JavaScript  
- LocalStorage  

## 🔗 Demo
https://gestor-de-tareas-lake.vercel.app/

## 🧱 Funcionalidades
- Crear tareas  
- Borrar tareas  
- Guardado automático con LocalStorage  
- Responsive básico  

## 📦 Instalación
Clonar el repo y abrir `index.html`.
